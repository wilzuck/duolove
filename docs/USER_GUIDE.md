# Guide utilisateur

## Commencer
1. **Créer un compte** : prénom ou pseudo, e-mail, mot de passe (10+ caractères, majuscule, minuscule, chiffre), date de naissance (**18 ans minimum**), genre, pays, ville. Aucun consentement marketing n'est requis.
2. **Confirmer l'e-mail** (lien reçu, valable 24 h) : indispensable pour liker et écrire.
3. **Compléter le profil** en 4 étapes : à propos de vous, centres d'intérêt, photos (recadrez avant d'envoyer), critères de rencontre. Plus le profil est complet (bio, 3 intérêts, 3 photos), plus il est visible.

## Découvrir et matcher
- **Glissez à droite** (ou ❤ / flèche →) pour liker, **à gauche** (✕ / ←) pour passer, ★ pour un Super Like (Premium), ↺ pour revenir sur le dernier profil passé (Premium). Touchez ⓘ pour le profil complet.
- Le **% de compatibilité** vient de vos intentions, intérêts communs, ville/pays, langues et activité — jamais de votre apparence.
- Quand deux personnes se likent, c'est un **match** : une conversation s'ouvre.
- Gratuit : 20 likes par jour. L'onglet *Likes* montre le nombre de personnes intéressées (liste complète avec Premium).

## Discuter
Messages, émojis et photos. ⋮ → *Mettre fin au match*, *Bloquer* ou *Signaler*. Vous pouvez supprimer vos propres messages. Les accusés de lecture se désactivent dans *Paramètres → Confidentialité*.

## Votre sécurité
- Ne **jamais envoyer d'argent** ni d'informations bancaires. Méfiez-vous des déclarations d'amour très rapides ou des refus de vidéo.
- Rencontrez-vous dans un lieu public, prévenez un proche.
- **Signalez** tout comportement suspect : un modérateur examine chaque signalement.
- Obtenez le **badge vérifié** (Profil → Vérification) : un modérateur compare un selfie à vos photos puis le supprime.

## Abonnements
*Premium* (2 500 FCFA/mois) : 100 likes/jour, 3 Super Likes, voir qui vous a liké, filtres avancés, retour arrière. *VIP* (5 000 FCFA/mois) : tout Premium + 10 Super Likes, 4 boosts/mois, mode discret. Annulable à tout moment (*Paramètres → Abonnement*) : vos avantages durent jusqu'à la fin de la période payée. Aucun avantage n'est activé tant que le paiement n'est pas confirmé. Factures : *Paramètres → Paiements*.

## Vos données
*Paramètres → Confidentialité* : masquer le profil, partager (ou non) une position **arrondie**, **exporter** vos données (JSON), **supprimer** votre compte. *Sécurité* : changer le mot de passe, déconnecter un appareil. *Comptes bloqués* : débloquer.
